# Current programme-guidance policy contracts

D2.5A defines the pre-exercise language for a training job. Policy inputs describe approved planning intent; slot definitions describe muscle/movement targets, purpose, ordered guidance, eligibility constraints and deterministic omission/substitution policy. Definitions contain no selected exercise, slot ID, exact target, load, rep, workout or block data.

The policy registry remains intentionally unimplemented. The pure D2 adapter accepts a definition plus separately supplied stable ID only.
