# Warm-Up Prescription Audit

Date: 2026-06-18  
Status: Audit only. No app code changed. No tests run. No EAS build started.

## Executive summary

Adaptive Strength Coach currently has a clean warm-up data model: warm-up sets are stored separately from work sets and are excluded from progression, PRs, volume, fatigue evidence, Strength Dashboard calculations, and Workout Review productive-set logic.

The actual warm-up prescription model is much simpler than the rest of the coaching architecture. It is best described as a warm-up load suggestion system, not a full evidence-based warm-up ramp system.

Current behavior:

- Known-load exercises receive three warm-up rows at 60%, 75%, and 90% of the displayed working load.
- Unknown-load exercises receive three percentage/effort rows derived from block and exercise role.
- Bodyweight exercises receive three identical `Bodyweight` warm-up rows.
- Warm-up rows do not prescribe reps.
- Warm-up row count does not scale with working weight.
- Compounds and isolations are only meaningfully differentiated when the working load is unknown.
- Opening exercises and later exercises use the same prescription; only the UI expansion default differs.

Final verdict: **C) Significant redesign recommended**.

This is not a launch-blocking data-safety issue, but it is a coaching-quality issue. Heavy opening compounds need dynamic ramps that scale with load and reduce reps as load increases. Accessories should usually use fewer, simpler warm-ups.

## Current logic

### Main generation path

Warm-up prescriptions are generated by:

`src/domain/training/load-display.ts`

The key function is:

`buildWarmupPrescriptions(exercise, metadata, targetUnit, blockType)`

The Train screen renders the generated rows through:

`app/(protected)/(tabs)/train.tsx`

The relevant row builder is:

`buildOverviewSetRows(...)`

Warm-up and work sets are separated by:

`src/domain/training/workout-sets.ts`

```ts
getWarmupSets(...)
getWorkSets(...)
```

### Warm-up set storage

Logged sets use:

```ts
type?: "warmup" | "work"
```

Warm-up rows are therefore first-class logged rows, but they are intentionally excluded from productive training evidence.

This part is good.

### Known-load exercise logic

If the exercise has a known or estimated working load:

1. The app reads the displayed working load through `loadDisplayForExercise`.
2. If the block is `deload`, the base load is reduced by 10% and rounded down to the exercise increment.
3. The warm-up percentages are always:

```text
60%
75%
90%
```

4. Each warm-up load is rounded up to the exercise load increment.
5. Estimated loads are labelled with `Est.`.

Example from existing test coverage:

```text
100kg known working load
W1: 60kg
W2: 75kg
W3: 90kg
```

Deload example from existing tests:

```text
100kg known working load in deload
base load reduced to 90kg
W1: 55kg
W2: 67.5kg
W3: 82.5kg
```

### Unknown-load exercise logic

If the app does not know the working load, it does not invent one. Instead, it shows percentage and effort guidance.

The unknown-load working range is determined by:

- block type
- exercise role
- exercise family
- primary muscles

The current unknown-load warm-up percentage rules are:

```text
If work range starts at 85% or reaches 95%: 50%, 70%, 80%
If work range starts at 80%:                 40%, 60%, 75%
If work range starts at 75%:                 40%, 55%, 70%
Otherwise:                                   30%, 45%, 55%
```

Effort labels:

```text
<=35%: easy warm-up
<=50%: warm-up
<=60%: close to working weight
>60%:  clean ramp-up
```

Example from existing tests:

```text
Hypertrophy unknown-load exercise
W1: 30% · easy warm-up
W2: 45% · warm-up
W3: 55% · close to working weight
```

### Bodyweight exercise logic

Bodyweight exercises receive three identical warm-up rows:

```text
W1: Bodyweight
W2: Bodyweight
W3: Bodyweight
```

This avoids the old bodyweight display bug, but it is not a meaningful ramp.

For pull-ups, dips, back extensions, Nordics, and similar bodyweight-capable movements, a better future model would distinguish:

- easier variation
- partial range or controlled tempo
- bodyweight technique set
- added-load ramp if weighted

### UI behavior

The Train screen renders warm-up rows inside each exercise card.

Important details:

- The first exercise has warm-ups expanded by default.
- Later exercises still receive warm-up rows, but the warm-up section is collapsed by default.
- The user can add warm-up rows up to six.
- The user can remove unlogged warm-up rows.
- If the user adds more rows than the generated three, the extra rows duplicate the final prescription.

That means adding a fourth warm-up row after a known-load exercise typically repeats the 90% suggestion.

### Rep prescription

Warm-up rows currently prescribe loads only.

They do not prescribe:

- reps
- rest
- intent
- bar speed
- whether a row is optional
- whether a row is a technique set, bridge set, or primer set

This is the largest gap between current behavior and coached warm-up practice.

## Production examples

These examples use the current production formula:

```text
Known load: 60%, 75%, 90% of working load
Rounded up to exercise load increment
```

Most barbell and machine exercises default to a 5kg increment. Cable and dumbbell exercises commonly use 2.5kg.

### Opening compound examples

The following applies to Bench Press, Barbell Back Squat, Deadlift, Military Press / Standing Barbell OHP proxy, and Barbell Row when using known kg loads and a 5kg increment.

| Working load | Current W1 | Current W2 | Current W3 | Audit |
| --- | ---: | ---: | ---: | --- |
| 60kg | 40kg | 45kg | 55kg | Reasonable enough for a moderate lift, but no bar/empty implement set. |
| 100kg | 60kg | 75kg | 90kg | Acceptable only for users who are already warm; still lacks a lower bridge. |
| 120kg | 75kg | 90kg | 110kg | First jump is aggressive for an opening compound. |
| 160kg | 100kg | 120kg | 145kg | Too few bridges for many lifters; no light rehearsal set. |
| 200kg | 120kg | 150kg | 180kg | Not coach-quality as a first warm-up sequence; first set is far too heavy for many users. |

The main issue is not that 60/75/90 is always bad. The issue is that the app uses exactly the same three rows regardless of whether the user is benching 60kg or deadlifting 200kg.

Accessory audit conclusion: the current model over-applies compound warm-up logic to isolation work when load is known.

## Evidence review

The evidence base for resistance-training warm-ups is less settled than the evidence base for volume, intensity, and progression. Still, there is enough practical agreement to judge the current system.

Useful evidence and coaching principles:

- Warm-ups prepare the body for the intensity required by later exercise, but the research does not identify one universally best warm-up structure. Source: [IntechOpen narrative review](https://www.intechopen.com/chapters/75109).
- Common benefits include increased temperature, lower joint and muscle stiffness, improved nerve impulse transmission, and increased blood flow. Source: [IntechOpen narrative review](https://www.intechopen.com/chapters/75109).
- Specific warm-ups generally use the same or similar movement at progressively higher intensities. Source: [IntechOpen narrative review](https://www.intechopen.com/chapters/75109).
- Recent resistance-training work suggests specific warm-ups can improve mechanical performance, especially when the warm-up is specific and not excessively fatiguing. Source: [MDPI Sports 2025 re-warm-up study](https://www.mdpi.com/2075-4663/13/5/142).
- Re-warm-ups may be more useful before a lower-body exercise later in the session than before bench press after squatting. Source: [MDPI Sports 2025 re-warm-up study](https://www.mdpi.com/2075-4663/13/5/142).
- A practical review of newer hypertrophy warm-up research reported that 80% of a 10RM for 5 reps outperformed lower-load warm-ups in one study, and suggested one lighter set plus one heavier set may be enough when already warm. Source: [Stronger by Science](https://www.strongerbyscience.com/heavier-warm-ups/).
- Practical coaching consensus is that loads should usually rise while reps fall as the lifter approaches working weight. Source: [MacroFactor warm-up guide](https://macrofactor.com/warm-up-resistance-training/).

The evidence does not require a complicated warm-up. It does support a few clear principles:

1. Specific warm-ups should generally get heavier over time.
2. Reps should generally decrease as load rises.
3. Heavy opening compounds need more gradual exposure than small accessories.
4. Warm-ups should improve readiness without becoming productive fatigue.
5. Later exercises may need fewer warm-ups unless the muscle group or movement demand changes materially.

## Evidence questions

### 1. Does current logic scale with working weight?

Partially.

It scales the load values by percentage, but it does not scale the number of warm-up sets or the size of early jumps.

A 60kg bench and a 200kg deadlift both receive exactly three rows. This is not enough scaling for heavy opening lifts.

### 2. Does current logic reduce reps as load increases?

No.

Warm-up rows do not prescribe reps at all.

### 3. Does current logic avoid excessive fatigue?

Mostly, but only because it does not prescribe reps.

The app avoids contaminating training evidence with warm-ups, which is excellent. But a user could interpret 90% warm-up rows as normal warm-up work and perform too many reps unless they already know how to ramp.

### 4. Does current logic treat compounds differently from isolations?

Only for unknown loads.

When working load is known, a barbell squat and a cable lateral raise both receive the same 60/75/90 pattern. This is too blunt.

### 5. Does current logic treat the opening exercise differently?

Only visually.

The first exercise warm-up section is expanded by default. The actual prescription is the same for opening and later exercises.

### 6. Would an experienced coach approve?

An experienced coach would likely approve the data separation and the simple unknown-load guidance.

They would likely not approve the known-load prescription as a universal warm-up model, especially for heavy barbell compounds and small isolation exercises.

## Opening compound analysis

### Bench Press

Current model:

- 60%, 75%, 90%
- no bar set
- no rep guidance
- same ramp whether first exercise or later exercise

Assessment:

Fine for moderate loads if the user knows what to do, but under-specified for heavy benching. Bench often benefits from a light technical rehearsal and one or two bridge sets before a heavier primer.

### Barbell Back Squat

Current model:

- same 60%, 75%, 90%

Assessment:

Less acceptable than bench for heavy loads. Squats use large muscle mass and high systemic demand. A first warm-up of 100kg for a 160kg working squat is too aggressive for many users.

### Deadlift

Current model:

- same 60%, 75%, 90%

Assessment:

Deadlift is the clearest mismatch. Heavy deadlifts need gradual exposure, but too many reps near working weight can create fatigue. The app should prescribe fewer reps as the load rises and should scale warm-up count with working load.

### Standing Barbell Overhead Press

Current library proxy:

- Strength Dashboard maps Standing Barbell Overhead Press to `Military Press`.

Assessment:

OHP often uses smaller absolute loads, so three rows can be excessive at low loads and insufficiently specific at higher loads. A bar/empty implement set plus one or two jumps is usually enough for many users.

### Barbell Row

Current model:

- same 60%, 75%, 90%

Assessment:

Rows need some ramping when heavy, but they rarely need the same treatment as a heavy squat or deadlift. The warm-up should depend on whether it is the first pull/hinge pattern of the day and whether the load is heavy.

## Accessory analysis

### Lat Pulldown

Lat pulldown can justify one or two warm-up sets when it is the first vertical pull of the session or when the working load is heavy. It should not automatically get the same number of rows as a squat.

### Cable Row

Cable row is similar to lat pulldown. One or two ramp sets are enough in most normal sessions. If it appears after deadlifts, rows, or pulldowns, fewer warm-ups are probably needed.

### Leg Extension

Leg extension can benefit from a light feeler set for knees and machine setup, but three percentage rows are usually unnecessary. For many users, one easy set and one near-working feel set is enough.

### Lateral Raise

The current prescription can collapse into duplicate rows due to rounding. A 10kg cable lateral raise becomes:

```text
7.5kg
7.5kg
10kg
```

This is not useful. Lateral raises should usually have either no formal warm-up or one light feeler set.

### Triceps Pushdown

At 20kg, the current sequence becomes:

```text
12.5kg
15kg
20kg
```

The final warm-up may equal the working load. That can be acceptable as a light practice set if reps are low, but the app does not prescribe reps, so it can be misread.

### Bicep Curl

Same as pushdowns. Curls do not need three default warm-up rows in most contexts.

## Recommended redesign

### Keep

Keep these current strengths:

- Warm-ups remain separate from work sets.
- Warm-ups remain excluded from progression, PRs, volume, fatigue evidence, and reporting.
- Unknown-load rows remain percentage/effort based instead of inventing fake loads.
- Users can edit, add, remove, and log warm-up rows.
- Deload and Recovery Window warm-ups remain lower-stress.

### Change

Replace the universal known-load 60/75/90 model with a dynamic ramp planner.

Inputs should include:

- exercise role
- movement pattern
- exercise family
- load kind
- working load
- load increment
- session position
- prior exercises in the session
- block type
- experience level
- known vs estimated vs unknown load

Output should include:

- warm-up row count
- load
- reps
- short purpose label
- optionality where appropriate

### Proposed dynamic ramp principles

#### Opening primary barbell compound

Use more gradual ramps as working load rises.

Possible shape:

| Working load band | Warm-up style |
| --- | --- |
| Light/moderate | bar or very light set, one middle bridge, one near-work primer |
| Moderate/heavy | bar, low bridge, middle bridge, near-work primer |
| Heavy | bar, several bridging sets, low-rep near-work primer |
| Very heavy | bar, multiple low-rep bridges, near-work single/double, no fatigue accumulation |

Reps should generally decrease as load rises:

```text
light set: 8-10 reps
middle bridge: 4-6 reps
heavier bridge: 2-4 reps
near-work primer: 1-2 reps
```

This should be a rule family, not hard-coded examples.

#### Later compound lifts

Use fewer early warm-ups if:

- the same muscle groups have already been trained
- the previous exercise was similar
- the movement is not a primary anchor

Still allow re-warm-up when:

- moving from upper to lower body
- moving from machine/isolation to heavy free-weight compound
- the next exercise has high skill or high systemic demand

#### Machine compounds

Use one to three warm-ups depending on working load and session position.

Machine compounds need setup and tissue preparation, but they usually do not need barbell-style empty-bar ramps.

#### Isolation exercises

Default to zero to two warm-up rows:

- zero if late-session, low load, familiar, and low-risk
- one light feeler set if first time or joint-sensitive
- two rows only if load is high or the movement is unusually demanding

#### Bodyweight exercises

Stop showing three identical `Bodyweight` rows.

Use better labels:

- easier variation
- controlled bodyweight reps
- bodyweight primer
- added-load ramp if weighted

Examples:

```text
Pull-Up
W1: Assisted or easy reps
W2: Bodyweight technique reps
Work: Bodyweight or Bodyweight + load
```

#### Unknown loads

Keep effort labels, but make row count role-aware:

- primary compound unknown: two to four rows
- secondary compound unknown: one to three rows
- isolation unknown: zero to two rows

#### Deload / Recovery Window

Use fewer, easier warm-ups:

- one to three rows for compounds
- zero to one for small accessories
- no high-novelty or high-fatigue ramping

## Implementation risk

Risk level: **moderate**.

Why it is manageable:

- Warm-up rows are already isolated from progression and reporting evidence.
- The core change can live inside `buildWarmupPrescriptions` and the row model.
- Work-set completion and progression do not need to change.

Risks to manage:

- Adding rep suggestions changes the UI model and tests.
- Existing users may be used to three warm-up rows.
- Extra warm-up rows currently duplicate the final row; this should be revised.
- Heavy lift ramps must avoid prescribing too much fatigue.
- Accessory simplification must not make the UI feel like warm-ups disappeared accidentally.

Recommended implementation approach:

1. Add a warm-up ramp domain model with role/load/session-position inputs.
2. Extend `WarmupPrescription` with optional `repsDisplay` or `repTarget`.
3. Preserve current three-row unknown-load behavior initially if UI risk is high.
4. Add tests for heavy compounds, light compounds, accessories, bodyweight, deload, and session position.
5. Update Training System Guide copy.

## Final verdict

The current system is safe from a data integrity perspective but too generic from a coaching perspective.

It does not currently match the same level of evidence-based prescription quality as:

- set prescription
- target zones
- exercise selection
- fatigue classification
- Recovery Window logic

Recommendation: **Significant redesign**.

Priority:

1. Heavy opening compound ramp scaling.
2. Rep guidance that decreases as load increases.
3. Accessory simplification.
4. Bodyweight warm-up labels that are not three identical rows.
5. Session-position-aware re-warm-up logic.

No code change was made as part of this audit.
