# Representative hypertrophy Upper programme-guidance policy

The sole supported input is intermediate `build_muscle`, four-day `upper_lower`, hypertrophy, normal productive `Upper` `upper-a`, with `full_gym` capability. It emits seven ordered pre-exercise jobs: horizontal press, horizontal pull, vertical press, vertical pull, lateral deltoid, optional elbow flexion, optional elbow extension.

Compound jobs precede isolation. The direct set ranges are conservative session guidance for one later-selected exercise; compound overlap is not counted as full direct arm/shoulder work. The policy contains no selected exercise or slot ID. All other roles, beginner, strength, power, deload and equipment combinations are explicit unsupported results.
