# Current planned-set performance facts

This B1A boundary extracts immutable planned work-set facts only from completed planned workouts with matching mesocycle, microcycle and session-index identity. Stored exact targets are matched by ordinal; ranges and current templates are never consulted. Custom and extra sessions are explicitly ignored.

Each fact is `exceeded`, `met`, `missed`, `incomplete`, `stopped`, or `invalid`. Stop status remains distinct from a miss. No aggregation, breadth, trend, fatigue, persistence, readiness, or decision work is included.

Phase 11A.2B1B will aggregate facts and breadth. B2/B3 will interpret trends and fatigue.
