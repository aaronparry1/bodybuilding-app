# Current exact-target evidence aggregation

B1B aggregates B1A facts only. It groups by exact workout/session-index/exercise identity, then by planned session, with deterministic fact ordering and duplicate conflict visibility. Counts preserve exceeded, met, missed, incomplete, stopped and invalid evidence. Breadth reports only sets, exercises and planned sessions.

This is not a trend, fatigue, successor, readiness, persistence or decision boundary. B2 consumes this structured window.
