# Canonical Design-QA Progress migration blocker

The canonical evidence → evaluation → decision → application pipeline is ready for generic continuation, review, insufficient-evidence, explicit transition, and explicit deload cases. It is not yet a complete owner for the 34 Design-QA Progress fixtures.

The remaining fixtures include load regression/escalation, productive-range and soft-cap decisions, volume recommendations, exercise rotation, goal-specific recommendation projections, recovery-capacity presentation, and phase-specific distinctions. None of those outcomes exists in the canonical Progress evaluation/decision contract or Mesocycle policy. Migrating them now would require inventing policy from fixture names or retaining legacy recommendation authority, both prohibited.

The exact affected fixture IDs and missing contracts are recorded in the deterministic blocker artifact. The normal Progress Design-QA bridge remains untouched; no hidden canonical adapter was added. The next phase must define these canonical Progress decision owners before fixture migration can proceed.
