# Session Prep Exercise Curation

Date: 2026-06-18

Status: audit / curation only. No code changes. No EAS build.

## 1. Executive Summary

Session Prep 2.0 should use a small, hand-picked, coach-approved exercise pool. The app should not randomly choose prep exercises from the main exercise library.

The current Session Prep system is workout-type-specific but not yet lift-specific. The next version should select from curated pools based on the first meaningful lift or session emphasis:

- Bench / horizontal press
- Overhead press
- Squat
- Deadlift / hinge
- Row / pull
- Pull-up / pulldown
- Lower body general
- Full body

Every prep flow should include:

- temperature / low-level blood flow
- relevant joint motion
- activation or support for the main pattern
- a core/bracing/control drill
- movement-specific rehearsal

Final curation principle:

Prep should make the first working sets feel better without becoming a second workout.

## 2. Curation Principles

Include an exercise only if it is:

- practical in a normal gym or home-gym context
- low fatigue
- easy to explain
- useful before a specific lift/session
- unlikely to interfere with the main lift
- safe for general users when performed conservatively
- clearly framed as training preparation, not medical treatment

Exclude an exercise if it is:

- obscure
- too medical/rehab-coded
- high skill
- high fatigue
- heavy enough to affect performance
- equipment-dependent in a way that blocks most users
- likely to distract from the main workout
- included only because it sounds clever

Default exercises should be:

- simple
- repeatable
- low-risk
- suitable for beginners
- directly tied to common lifting patterns

Optional exercises can be:

- slightly more specific
- useful for experienced users
- useful when equipment is available
- a better fit for a particular lift emphasis

## 3. Universal Prep Rules

Every Session Prep should include some version of the following:

1. Raise temperature

Use easy movement or light high-rep work. This should feel like preparation, not conditioning.

2. Mobilise relevant joints

Use controlled range, not aggressive stretching. The goal is usable position for the session.

3. Activate/support key muscles

Use light work for the muscles that stabilise or support the first lift.

4. Core/bracing/control drill

Every serious lift needs trunk position and force transfer. Prep should include at least one low-fatigue drill for bracing, anti-extension, anti-rotation, pelvic control, or trunk stiffness.

5. Movement-specific rehearsal

The final prep movement should resemble the first major pattern: press, squat, hinge, pull, or full-body coordination.

Universal constraints:

- 4-6 movements max.
- 3-8 minutes total for most sessions.
- No hard sets.
- No grinding.
- No failure.
- No PRs.
- No progression evidence.
- No fatigue scoring.

## 4. Candidate Exercise Pools

### Universal Core / Bracing

#### Dead Bug

- Purpose: anti-extension control and rib/pelvis position.
- Why include: simple, low fatigue, useful before pressing, squatting, hinging, and full-body work.
- Prepares: trunk control, pelvic position, breathing behind a brace.
- Core/bracing/control role: primary bracing drill.
- Suggested prescription: 1-2 x 5-8 each side.
- Risk level: low.
- Beginner suitability: yes.
- Default or optional: default.

#### Bird Dog

- Purpose: trunk control with opposite-arm/opposite-leg movement.
- Why include: useful for hinge, squat, pull, and full-body sessions without fatigue.
- Prepares: anti-rotation, hip control, spinal position.
- Core/bracing/control role: primary control drill.
- Suggested prescription: 1-2 x 5 each side.
- Risk level: low.
- Beginner suitability: yes.
- Default or optional: default for hinge/pull/lower/full-body.

#### Front Plank

- Purpose: simple trunk stiffness and anti-extension.
- Why include: familiar and easy to scale.
- Prepares: bracing, rib position, trunk stiffness.
- Core/bracing/control role: primary bracing drill.
- Suggested prescription: 1-2 x 10-25 sec.
- Risk level: low.
- Beginner suitability: yes.
- Default or optional: default where Dead Bug is not used.

#### Side Plank

- Purpose: lateral trunk stiffness and pelvis control.
- Why include: useful for squat, deadlift, loaded carries, and unilateral lower work.
- Prepares: anti-lateral-flexion, hip/trunk control.
- Core/bracing/control role: primary lateral bracing drill.
- Suggested prescription: 1 x 10-20 sec each side.
- Risk level: low.
- Beginner suitability: yes, with knee regression.
- Default or optional: optional.

#### McGill Curl-Up

- Purpose: low-motion trunk endurance.
- Why include: useful when the session benefits from bracing practice without flexion volume.
- Prepares: trunk stiffness and controlled brace.
- Core/bracing/control role: primary bracing drill.
- Suggested prescription: 2-3 x 5-8 sec holds.
- Risk level: low.
- Beginner suitability: yes.
- Default or optional: optional.

#### Pallof Press

- Purpose: anti-rotation control.
- Why include: excellent general bracing drill if cable/band is available.
- Prepares: trunk control under lateral/rotational demand.
- Core/bracing/control role: anti-rotation drill.
- Suggested prescription: 1-2 x 8-10 each side.
- Risk level: low.
- Beginner suitability: yes.
- Default or optional: optional because it needs a band/cable.

### Bench / Horizontal Press Prep

#### Band Pull-Apart

- Purpose: upper-back activation and shoulder position.
- Why include: simple, low fatigue, directly supports pressing setup.
- Prepares: scapular control, upper-back tightness for bench.
- Core/bracing/control role: indirect; improves upper-back platform while trunk drill handles bracing.
- Suggested prescription: 1-2 x 15-25.
- Risk level: low.
- Beginner suitability: yes.
- Default or optional: default.

#### Face Pull

- Purpose: rear delt / external rotation / scapular control.
- Why include: useful before bench and pressing without loading pressing muscles hard.
- Prepares: shoulder position, upper-back control.
- Core/bracing/control role: indirect; pair with Dead Bug or Front Plank.
- Suggested prescription: 1-2 x 12-20.
- Risk level: low.
- Beginner suitability: yes.
- Default or optional: default if cable/band available.

#### External Rotation

- Purpose: rotator cuff control.
- Why include: very low fatigue and useful before heavy pressing.
- Prepares: shoulder rotation control.
- Core/bracing/control role: indirect; not a trunk drill.
- Suggested prescription: 1 x 10-15 each side.
- Risk level: low.
- Beginner suitability: yes.
- Default or optional: default.

#### Light DB Floor Press or Push-Up

- Purpose: rehearse horizontal pressing with low load.
- Why include: pattern-specific rehearsal before bench without needing a barbell.
- Prepares: press path, shoulder position, elbow rhythm.
- Core/bracing/control role: push-up version adds trunk stiffness; floor press version does not.
- Suggested prescription: 1-2 x 8-15 easy reps.
- Risk level: low.
- Beginner suitability: yes, with incline push-up regression.
- Default or optional: default.

#### Light Pullover

- Purpose: controlled shoulder flexion and lat/chest opening.
- Why include: can help pressing position and rib control when kept very light.
- Prepares: shoulder range, lats, rib position.
- Core/bracing/control role: reinforces ribs-down control if cued correctly.
- Suggested prescription: 1 x 8-10 easy reps.
- Risk level: low to moderate if overloaded.
- Beginner suitability: yes with very light load or band.
- Default or optional: optional.

## 5. Recommended Default Templates

### Bench First

4-6 movements max:

1. Dead Bug: 1 x 5-8 each side
2. Band Pull-Apart: 1 x 15-25
3. External Rotation: 1 x 10-15 each side
4. Face Pull: 1 x 12-20
5. Light DB Floor Press or Push-Up: 1 x 8-15 easy reps

Optional:

- Light Pullover: 1 x 8-10 if shoulder/lat position needs more prep.

Why:

Bench needs bracing, upper-back platform, cuff control, scapular control, and light pressing rehearsal.

### Squat First

4-6 movements max:

1. Cat-Camel: 5 easy reps
2. Dead Bug or Front Plank: 1 x 5-8 each side or 1 x 15-25 sec
3. Ankle Floss / Knee-to-Wall Rock: 1 x 8 each side
4. Deep Squat Hold: 1 x 20-30 sec
5. Goblet Squat: 1 x 8-10 easy reps

Optional:

- Glute Bridge: 1 x 8-12.
- Full Range Split Squat: 1 x 5 each side.

Why:

Squat needs trunk position, ankles, hips, bottom-position ownership, and light pattern rehearsal.

### Deadlift First

4-6 movements max:

1. Bird Dog: 1 x 5 each side
2. Hip Hinge Drill: 1-2 x 6-10 slow reps
3. Glute Bridge: 1 x 8-12
4. Back Extension: 1 x 10-15 easy reps
5. Light hinge rehearsal with empty bar / kettlebell / bodyweight: 1 x 6-8

Optional:

- Side Plank: 1 x 10-20 sec each side.
- Hamstring Sweep / Dynamic Hamstring Reach: 1 x 6-8 each side.

Why:

Deadlift needs bracing, hip hinge shape, posterior-chain temperature, and clean lockout mechanics without fatigue.

### OHP First

4-6 movements max:

1. Dead Bug: 1 x 5-8 each side
2. Wall Slide: 1 x 8-10
3. External Rotation: 1 x 10-15 each side
4. Trap 3 Raise: 1 x 8-12
5. Scap Push-Up or Light Landmine Press: 1 x 8-10

Optional:

- Face Pull: 1 x 12-20.

Why:

OHP needs trunk/rib control, overhead range, cuff control, scapular upward motion, and low-fatigue press rehearsal.

### Pull First

4-6 movements max:

1. Bird Dog or Dead Bug: 1 x 5 each side
2. Band Pull-Apart: 1 x 15-25
3. Face Pull: 1 x 12-20
4. Straight-Arm Pulldown: 1 x 12-20
5. Light Row or Scapular Pulldown: 1 x 8-12

Optional:

- Trap 3 Raise: 1 x 8-12.
- Light Curl: 1 x 12-15 if elbow flexion is a major part of the session.

Why:

Pulling needs trunk position, scapular control, lat path, upper-back readiness, and pattern rehearsal.

## 6. Exclusion List

### Neck Bridge Progression

Reason:

Too advanced and too sensitive for general Session Prep. Keep out of default consumer prep.

### Heavy Carries

Reason:

Useful training tool, but can fatigue grip/trunk before the main session. Keep for capacity work, not default prep.

### Heavy Back Extensions / Weighted Back Extensions

Reason:

Can become posterior-chain work. Use only light bodyweight back extension as optional hinge prep.

### Long Static Stretching

Reason:

Can reduce readiness if aggressive or excessive. Prep should use controlled motion and brief holds.

### High-Rep Failure Pump Work

Reason:

Prep should raise temperature and awareness, not pre-fatigue muscles needed for the workout.

### Complex Olympic Lift Drills

Reason:

Too technical for general prep and too dependent on coaching context.

### Aggressive Banded Distraction / Joint Mobilisation

Reason:

Too rehab/therapy-coded and can be misused. Avoid medical framing.

### Plyometrics For General Users

Reason:

Can be useful for Power/Athletic Performance, but should not appear as generic prep without goal/block context.

### Neck Isometrics / Neck Harness Work

Reason:

Potentially useful for specific sports, but not appropriate as default general strength prep.

### Random Mobility Flows

Reason:

Too vague. Every prep exercise should map to a lift or session need.
