# Current programme specification construction

D2 constructs an initial D1 programme specification from approved pre-exercise session-role and prescription-slot definitions. All programme, template and slot identities are supplied; no exercise, generated setting, repository or runtime plan is read. Initial programme and target versions are `1`.

An optional bound first-microcycle programme reference is a pure proposal only. Plan setup, persistence and session construction remain unchanged.

D2.5 now defines and certifies one four-template pre-exercise policy family, but D2 remains unintegrated. D2.5D1 supplies an exact-purpose registry whose entries are all non-executable; D2.5D2 must approve base equivalence and a dedicated calibration policy is still required because production new plans begin in `hypertrophy_calibration`, not the candidate base purpose.
