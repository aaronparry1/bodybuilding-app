# App Store Screenshot Strategy

## Executive Summary

The new screenshot pack should replace the current developer-style screenshots entirely. The goal is not to document the UI screen by screen; the goal is to make a cold App Store visitor understand the outcome in seconds.

The sequence uses a premium black and gold brand system, large benefit-led headlines, and real app screens as supporting proof. The composition intentionally puts the message first and the app screen second.

## Strategy

Target device: 6.7-inch iPhone portrait.

Final size: 1284 x 2778 px.

Composition: roughly 80% benefit/message and 20% app proof.

Visual approach:

- dark premium gym aesthetic
- gold accent colour
- bold, high-contrast typography
- real in-app screens framed as proof
- no private user data
- no unsupported performance claims

## Screenshot Sequence

1. STOP GUESSING. START PROGRESSING.

This opens with the strongest product promise. It positions Adaptive Strength Coach as the answer to uncertainty in training.

2. BUILD MUSCLE. BUILD STRENGTH.

This speaks to the broadest core audience: lifters who want hypertrophy and performance without choosing between them.

3. YOUR ROADMAP. ALREADY PLANNED.

This differentiates the app from basic workout trackers. The user sees that the product plans phases, not just individual sessions.

4. KNOW WHEN YOU'RE IMPROVING.

This promotes the Strength Dashboard, PR tracking, and e1RM tracking. It answers the user question: “Is this working?”

5. TRAIN HARD. RECOVER SMART.

This introduces Recovery Windows and fatigue management. It makes the product feel more like coaching than a static gym log.

6. POWERLIFTING? COVERED.

This directly targets strength athletes and makes the Powerlifting Meet mode visible.

7. BUILT FOR REAL LIFTERS.

This closes with training review and progression feedback. It reinforces that the app is for practical gym use, not generic fitness content.

## Upload Recommendation

Upload all seven screenshots in the listed order. If Apple limits visible preview space in search results, screenshots 1-3 are the most important because they communicate promise, outcome, and planning structure immediately.

## Replacement Recommendation

Replace the current screenshots entirely. The existing set is useful for QA and documentation, but it is too UI-led for conversion and does not sell the product outcome quickly enough.
