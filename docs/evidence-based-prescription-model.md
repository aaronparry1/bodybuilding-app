# Evidence-Based Prescription Model

This document defines the prescription model Adaptive Strength Coach should use before replacing generic/default set prescriptions.

It is not a claim that every user needs identical volume. It is a bounded model: autoregulation still decides whether the user pushes, holds, or pulls back, but the starting prescription should sit inside sensible evidence-based boundaries.

## Sources and evidence quality

High-confidence inputs:

- ACSM progression models for resistance training describe goal-specific loading, set, rep, sequencing, and power-training principles for healthy adults.
- Schoenfeld, Ogborn, and Krieger's dose-response meta-analysis supports a graded relationship between weekly resistance-training volume and hypertrophy, with higher weekly set categories generally producing greater hypertrophy than very low volume.
- Ralston and colleagues' set-volume meta-analysis suggests moderate-to-higher weekly set volumes can help strength, but strength has stronger specificity and diminishing-return constraints than hypertrophy.
- Tapering literature and coaching consensus support reducing training volume while maintaining specificity/intensity close to maximal-strength events.
- Power-training consensus favours low-to-moderate volume, high intent, adequate rest, and avoiding fatigue-driven grinding.

Practical coaching assumptions:

- Direct hard sets are counted more strongly than indirect work.
- Smaller muscles and isolation work usually tolerate more local sets than heavy axial compounds.
- Beginners need fewer exercises and fewer hard sets to progress.
- Advanced users may tolerate more volume, but only if performance and recovery support it.
- Autoregulation from logged reps/load/drop-off replaces subjective RPE/RIR prompts.
- Recovery Window is adaptive transition/recovery work, not a mandatory fixed deload dose.

Reference links:

- ACSM 2009 Position Stand, Progression Models in Resistance Training for Healthy Adults: https://pubmed.ncbi.nlm.nih.gov/19204579/
- ACSM resistance training progression guidance: https://pubmed.ncbi.nlm.nih.gov/19204579/
- Schoenfeld et al. 2017 weekly set volume and hypertrophy meta-analysis: https://pubmed.ncbi.nlm.nih.gov/27433992/
- Ralston et al. 2017 weekly set volume and strength meta-analysis: https://pmc.ncbi.nlm.nih.gov/articles/PMC5684266/
- Pritchard et al. tapering for maximal strength: https://research.bond.edu.au/en/publications/effects-and-mechanisms-of-tapering-in-maximizing-muscular-strengt/

## 1. Hypertrophy

### Philosophy

Hypertrophy blocks should build muscle and work capacity with enough weekly hard sets to stimulate growth while letting logged performance and drop-off control the real dose.

The app should not force RPE/RIR. It should infer useful work from:

- completed productive sets
- reps achieved within target range
- load progression
- drop-off/shutdown
- fatigue classification
- exercise history
- volume learning

### Weekly volume targets

Use ranges, not exact mandates.

Intermediate hypertrophy baseline:

- Major muscle groups: 8-16 direct hard sets/week
- High-priority or well-recovering muscles: up to 18-20 sets/week if evidence supports it
- Small muscle groups: 6-14 direct sets/week
- Core/trunk: 2-6 direct exposures/sets/week depending split and goal

Beginner baseline:

- Major muscles: 5-10 sets/week
- Small muscles: 3-8 sets/week
- Core/trunk: 1-4 sets/week

Advanced baseline:

- Major muscles: 10-20 sets/week
- Small muscles: 8-16 sets/week
- Core/trunk: 2-8 sets/week

Do not automatically chase the top of these ranges. Volume increases require strong evidence.

### Session volume targets

Hypertrophy sessions should normally place:

- primary compounds at 3 required sets, target 3-5
- secondary/unilateral/machine compounds at 2 required sets, target 2-4
- isolation at 2 required sets, target 2-4
- small muscle accessories at 2 required sets, target 2-5
- core/bracing at 2 required sets, target 2-3

Slot role owns prescription before equipment category. If Hack Squat, Leg Press, Smith Squat, or another machine lower-body compound fills the primary lower-body slot, it should receive the primary lower-body prescription. Machine equipment can influence exercise scoring and fatigue context, but it should not automatically downgrade a primary slot to secondary machine-compound volume.

### Rep ranges

Suggested ranges:

- Primary compounds: 6-10 or 8-12
- Secondary compounds: 8-12
- Unilateral work: 8-15
- Isolation: 10-20
- Small muscle isolation: 12-25
- Core flexion: 10-20
- Core stability: time or 8-15 controlled reps where applicable

### Fatigue management

Hypertrophy can use higher volume than strength/power, but not unlimited volume.

Autoregulation can:

- add volume to low-fatigue accessories when recovery/performance is strong
- bias ranges high when evidence supports more work
- hold when evidence is unclear
- reduce accessory/support work first when fatigue appears

It should not:

- add heavy compound volume aggressively
- expand volume in taper/event week
- ignore repeated drop-off or shutdown

## 2. Strength

### Philosophy

Strength blocks should prioritise specificity, main-lift practice, controlled heavy exposure, and accessories that support the main lifts.

Primary lifts:

- Bench Press
- Squat
- Deadlift
- Standing Barbell Overhead Press

### Main lift exposure

Main lifts should stay stable unless there is a deliberate reason:

- stall evidence
- approved structured variation
- pain/limitation
- equipment limitation
- block transition

Typical primary lift prescription:

- required: 3
- target: 3-5
- soft cap: 5
- reps: 2-6, commonly 3-5

### Secondary lifts

Secondary lifts should support the main lift:

- close variations
- upper-back support
- hamstring/glute support
- triceps support
- unilateral support
- bracing/core support

Typical:

- required: 2
- target: 2-4
- soft cap: 4
- reps: 5-8 or 6-10 depending role

### Accessory volume

Strength accessories should be targeted, not generic bodybuilding leftovers.

Typical:

- required: 2
- target: 2-3
- soft cap: 3-4

### Core/bracing support

Strength plans should guarantee trunk/bracing exposure, especially on Lower/Legs/Full Body.

Suitable exercises:

- Cable Crunch
- Front Plank
- Side Plank
- Pallof Press
- Ab Wheel for suitable non-beginners
- Dead Bug / Bird Dog for lower-fatigue or Recovery Window work
- Back Extension / Reverse Hyper as posterior-chain support, not a complete abs replacement

## 3. Power

### Philosophy

Power blocks should protect speed and intent.

Power work should:

- happen early
- stay crisp
- stop before grinding
- use lower fatigue
- avoid hypertrophy-style junk volume

### Exercise selection

Beginner-safe options:

- Box Jump
- Broad Jump
- Medicine Ball Chest Throw
- Medicine Ball Overhead Throw
- Medicine Ball Rotational Throw
- Speed squat/press/deadlift when technically suitable

Advanced options:

- Power Clean
- Hang Power Clean
- Power Snatch
- Clean Pull
- Snatch Pull
- High Pull

### Volume constraints

Typical:

- power movement required: 3
- target: 3-5 for most loaded power work
- target: 3-6 for low-fatigue jumps/throws when quality remains high
- soft cap: 5-6
- reps: 1-5

Strength support:

- required: 2
- target: 2-4
- soft cap: 4

Accessories:

- required: 1
- target: 1-3
- soft cap: 3

Autoregulation:

- push only when power quality is sharp
- hold when acceptable
- pull back when degrading

## 4. Peak

### Philosophy

Peak blocks should express strength, maintain specificity, and reduce fatigue.

Peak should not look like normal strength training with the name changed.

### Prescription

Specific main lift:

- required: 2
- target: 2-4
- soft cap: 4
- reps: 1-4
- volume expansion: heavily restricted

Specific secondary:

- required: 1
- target: 1-3
- soft cap: 3

Support:

- required: 1
- target: 1-2
- soft cap: 2

Novelty should be minimal. Accessories should be familiar and low fatigue.

For Powerlifting Meet peak work, late peak should prefer canonical/specific squat, bench, deadlift, and standing overhead press exposures where the slot pattern calls for them. New specialty bars, overload tools, complex variants, and unfamiliar accessories should be suppressed unless pain/equipment constraints force the change.

## 5. Recovery Window

### Philosophy

Recovery Window is a planned recovery opportunity plus reactive readiness decision.

It should:

- reduce stress
- maintain movement quality
- prefer familiar exercises
- avoid high-skill novelty
- avoid overload chasing
- transition into the next block

### Prescription

Easy compound:

- required: 1
- target: 1-3
- soft cap: 3

Accessory/recovery movement:

- required: 1
- target: 1-2
- soft cap: 2

Core/bracing:

- required: 1
- target: 1-2
- soft cap: 2

Progression:

- none or maintenance only
- no aggressive load chasing

## 6. Get Leaner

### Philosophy

Get Leaner is not calorie tracking. The training goal is to preserve strength and muscle while supporting recovery capacity and sustainable consistency.

### Training bias

- Preserve primary lift exposure.
- Keep hypertrophy volume around minimum-effective to moderate ranges.
- Avoid excessive fatigue.
- Use recovery/cardio recommendations more often.
- Avoid aggressive volume chasing.

### Volume

Typical:

- major muscles: 6-12 direct sets/week
- small muscles: 4-10 direct sets/week
- trunk: 2-6 weekly sets/exposures

Autoregulation:

- progression can still happen when earned
- hold more readily under fatigue
- volume additions should be conservative and accessory-focused

## 7. Powerlifting Meet

### Philosophy

Powerlifting Meet should be specific to:

- Squat
- Bench Press
- Deadlift

The late plan should reduce novelty and fatigue while keeping readiness high.

### Base/build phase

- main lifts and close variations
- upper-back, triceps, hamstrings, glutes
- trunk/bracing guaranteed

### Specificity/peak/taper phase

- competition/canonical lifts become dominant
- variation and novelty decrease
- accessories reduce
- fatigue dissipates
- hard conditioning and unnecessary extra volume suppressed

### Trunk support

Powerlifting Meet should guarantee trunk/bracing exposure outside the final taper if recovery allows.

Peak Full Body for Powerlifting Meet should still keep direct low-volume bracing support. The intent is squat/deadlift readiness and trunk skill retention, not aggressive ab overload.

Suitable:

- Cable Crunch
- Front Plank
- Pallof Press
- Ab Wheel if experienced
- Back Extension / Reverse Hyper as posterior-chain support

## Weekly muscle-group volume targets

These are planning guardrails, not hard commands.

### Hypertrophy intermediate

- Chest: 8-16 direct sets
- Back/lats: 10-18
- Upper back/rear delts: 6-14
- Quads: 8-16
- Hamstrings: 6-14
- Glutes: 6-14
- Calves: 4-12
- Side delts: 6-14
- Front delts: mostly indirect, 0-6 direct
- Rear delts: 4-12
- Biceps: 6-12
- Triceps: 6-12
- Abs/core/trunk: 2-6

### Strength intermediate

- Main lift exposures: 2-4 per lift/week depending split and phase
- Chest/press support: 4-10
- Back/upper back: 6-14
- Quads: 4-10
- Hamstrings/glutes: 4-10
- Arms: 2-8
- Abs/core/trunk: 2-6, guaranteed

### Power intermediate

- Power exposures: 2-4 sessions/week where goal supports it
- Major muscle support: 4-10
- Accessories: 2-6
- Abs/core/trunk: 2-6, especially rotation/bracing for athletic goals

### Peak

- Specific lift exposure maintained
- Accessories reduced to 1-4 sets per muscle/week where useful
- Core/trunk 1-4 low-fatigue exposures if familiar

### Recovery Window

- roughly 40-60% of normal weekly hard-set exposure
- low fatigue
- familiar movement patterns
- no aggressive volume expansion

### Get Leaner

- Major muscles: 6-12
- Small muscles: 4-10
- Core/trunk: 2-6
- Recovery/cardio more prominent
- volume additions conservative

### Powerlifting Meet

- Squat/Bench/Deadlift specific exposure prioritised
- Upper-back, triceps, hamstrings/glutes, trunk guaranteed in base/build
- Accessories and novelty decrease as event approaches

## Core/trunk architecture

Core should be a programmed support system, not accidental filler.

Minimum exposure rules:

- Strength: at least 1 trunk/bracing slot weekly, preferably 2 when split allows.
- Powerlifting Meet: at least 1-2 trunk/bracing exposures weekly outside final taper; taper keeps only familiar low-fatigue work.
- Power/Athletic Performance: include bracing/rotation/anti-rotation where compatible with fatigue.
- Lower/Legs: include trunk support unless session length, fatigue, or Recovery Window constraints justify omission.
- Hypertrophy: core is useful but should not displace priority muscle work unless the split lacks trunk exposure elsewhere.
- Beginner Power Lower/Legs: preserve safe low-skill trunk/bracing before optional support when trimming session length.

Preferred exercise categories:

- Loaded flexion: Cable Crunch, Machine Crunch, Standing Cable Crunch.
- Stability/bracing: Front Plank, Side Plank, Dead Bug, Bird Dog.
- Anti-rotation: Pallof Press.
- Advanced anterior core: Ab Wheel Rollout.
- Posterior-chain trunk support: Back Extension and Reverse Hyper variants, classified as posterior-chain support rather than direct abs.

When to reduce/skip:

- high systemic fatigue
- heavy lower session already overloaded
- peak/taper/event week
- pain/limitation reason
- beginner with excessive session complexity

## Implementation direction

Implement in this order:

1. `slot-prescription-matrix.ts`
2. slot-specific set prescriptions in generated workout slots
3. explicit core/trunk guarantee slots
4. weekly muscle volume guardrails
5. autoregulation boundaries that respect matrix caps

Autoregulation must:

- push within upper bounds
- hold when evidence is unclear
- pull back when fatigue/drop-off appears
- avoid identical ranges for every slot unless the matrix explicitly says so
- avoid volume additions beyond evidence-based caps

- hybrid set ranges

## Productive vs regressive fatigue evidence

Shutdown/drop-off is objective evidence, but it is not automatically negative.

Adaptive Strength Coach separates shutdown evidence into:

- productive shutdown: hard work was capped after useful target work
- expected local fatigue: local fatigue appeared after useful work in a block that tolerates hypertrophy fatigue
- neutral shutdown: shutdown exists but does not clearly indicate recovery failure
- regressive shutdown: performance dropped before useful work was complete or a key lift is trending down
- systemic fatigue: multiple key lifts/sessions show regressive evidence

Hypertrophy and Powerbuilding can tolerate more local fatigue, especially on isolation, machine, accessory, calves, arms, and delt work after target work is complete.

Strength protects primary compounds more strongly.

Power and Peak are stricter because speed, sharpness, and specificity matter more.

Recovery Window recommendations should require regressive or systemic evidence, not merely a high count of productive shutdowns.

Hard productive work should usually lead to:

- continue the block
- hold volume
- monitor the next session
- reduce only the affected exercise or muscle if needed

Recovery Window is appropriate when:

- shutdowns happen early
- useful work is missed
- primary compounds decline
- multiple unrelated lifts are affected
- performance falls across sessions
- fatigue persists despite conservative work
