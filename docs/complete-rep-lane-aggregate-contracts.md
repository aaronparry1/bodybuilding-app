# Complete rep/lane aggregate contracts

D4E3C4B extends the isolated compatibility semantic model to preserve why a rep or lane branch won. The new v2 structures carry normalized branch facts, authority candidates, selected and rejected authority IDs, collision reason codes, explicit rep source, all eight current lane identities, rep/lane pairing, and generated-settings ownership metadata.

The registry is data-only and remains isolated from production helpers. It does not resolve precedence, execute arithmetic, construct settings, or route callers. Existing v1 seven-branch fixtures remain historical and are not silently reinterpreted. D4E3C4C is the next phase for complete precedence resolution and equivalence testing.
