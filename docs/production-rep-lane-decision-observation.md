# Production rep/lane decision observation

D4E3C4D2 adds a test-only read-only adapter around existing rep and lane helper results. It captures observable rep ranges and lane identities without predicting authority, importing v2, changing formulas, adding callbacks, or modifying production outputs.

The adapter confirms the three ordinary branches already equivalent and records that override, advanced-method, family-collision, role, special-family, planned-order final-authority, and partial-façade decisions remain unobservable or incomplete under current contracts. No production seam was added because the existing helper outputs are sufficient for ordinary branches and insufficient for the remaining authority winners.

Certification remains blocked; D4E3C4E must not begin. The next phase should add a narrow production diagnostic seam only where a real decision cannot otherwise be observed, with output-neutrality tests before any caller migration.
