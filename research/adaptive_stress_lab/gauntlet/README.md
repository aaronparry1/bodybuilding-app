# Coaching Gauntlet v0.1

Research-only stress test library for Adaptive Strength Coach V2.

Levels:

1. Level 1 - Normal Progression
2. Level 2 - Real Life
3. Level 3 - Coaching Judgement
4. Level 4 - Expert Coaching

The objective is not to make the Decision Engine look good. The objective is to expose poor decisions before any production integration.

Run:

```bash
node research/adaptive_stress_lab/src/run_coaching_gauntlet_v0_1.mjs
```

Report:

```text
reports/adaptive_stress_lab/coaching_gauntlet_v0_1.md
```
