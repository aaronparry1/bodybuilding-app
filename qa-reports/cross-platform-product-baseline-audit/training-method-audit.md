# Controlled training-method audit

Production reachability tests establish canonical straight sets plus a bounded grouped-method family (including antagonist supersets and rest-pause fixtures). Numerous historical/legacy method modules mention broader systems, but existence is not mounted support.

| Method | Reachability | Rule completeness verdict |
|---|---|---|
| Straight sets | mounted default | explicit targets, rest, progression, stop/fallback/tests |
| Antagonist supersets | mounted/certified fixture | execution identity and next-step semantics tested; long-term superiority not claimed |
| Rest-pause | mounted/certified fixture | eligibility/stop semantics tested; fatigue policy needs scientific registry |
| Drop sets | policy references/legacy possible | not claimed mounted without runtime trace |
| Clusters | domain support references | not claimed mounted |
| Trisets/ladders/pyramids/AMRAP | scattered model/system support | unverified production reachability |
| Eight Across, 5/3/1, BBB, dynamic/max effort, 100-rep, 10x10 | historical/domain concepts | not current mounted product claims |
| Top set + back-off | prescription structures exist | exact mounted breadth unverified |

Each future method definition must specify purpose, goal/phase/exercise eligibility, contraindications, target/load generator, progression, stop/exit, fatigue cost, plan interaction, fallback, explanation and golden tests. Novelty alone is prohibited. Current method authority correctly falls back to straight sets when identity/evidence is unsupported.
