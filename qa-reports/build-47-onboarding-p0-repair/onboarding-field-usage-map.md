# Onboarding field usage map

| Field | Meaning | Production consumer | Resolution |
| --- | --- | --- | --- |
| Goal | New programme outcome | canonical macrocycle/plan construction | retained |
| Target date | Optional event constraint | macrocycle construction | conditional |
| Training days | Future sessions the athlete can sustain | canonical microcycle frequency and programme construction | retained, 2–6 |
| Workout length | Available duration per new session | Session Construction feasibility and duration | retained |
| Framework | Executable split choice | canonical plan construction | shown only when multiple executable choices exist |
| Experience | Training-age constraint | canonical construction and starting prescription context | retained |
| Recent continuity | Whether the athlete is training or returning | canonical starting-volume policy | retained |
| Recent training days | Historical frequency before today | canonical starting-volume policy only | retained conditionally for `currently_training`; derived as zero otherwise |
| Typical recent workload | Historical workload | canonical starting-volume policy | retained |
| Recovery/cardio preference | Current setup preference | canonical programme constraints | retained |
| Units | Load display and increment system | canonical constraints | retained |

No retained answer is onboarding theatre. Future schedule and historical frequency remain separate in the construction command and are labelled separately in the review summary.
