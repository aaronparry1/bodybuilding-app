# D2 programme specification constructor map

| Input | Owner | Output |
| --- | --- | --- |
| plan/mesocycle/programme IDs | caller-approved planning identity | specification lineage |
| ordered session roles/purpose | current planning intent | stable session templates |
| muscle/pattern/slot purpose, range and constraints | approved pre-exercise programme guidance | stable prescription slots |
| supplied child IDs | caller ID provider | non-positional child identity |

The constructor consumes no generated exercise setting, selected exercise, block, repository or workout. E2E3 target identity maps directly to the constructed programme/template/slot fields. D3 will persist new-plan specifications; D4 will project them into construction.
