# D2.5A programme-guidance policy contract map

| Contract | Authority | Later consumer |
| --- | --- | --- |
| policy input | current planning intent before selection | policy registry |
| semantic target | muscle or movement pattern, never selected exercise | slot definition / selection |
| purpose | training-job taxonomy | slot policy |
| constraints | exercise eligibility, not exercise choice | selection |
| slot definition | pre-exercise min/max sets and deterministic rules | D2 constructor |

Initial policy versions are explicit and unsupported purposes must return an explicit result. D2 maps definitions only after caller-supplied IDs; no generated setting is an identity source.
