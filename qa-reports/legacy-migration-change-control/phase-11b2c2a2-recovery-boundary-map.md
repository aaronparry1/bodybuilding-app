# Stage 2C2A2 recovery boundary map

| Legacy dependency | Meaning | Current replacement |
| --- | --- | --- |
| Strategic title contains deload/recovery | Legacy recovery recommendation | Persisted current `deload` decision. |
| High systemic/mixed legacy fatigue classifier | Recovery prioritisation | Explicit current recovery context state; no watch-to-deload conversion. |
| Accepted legacy deload marker | Recovery active presentation | Current microcycle `deload` progression state. |

Recovery priority is a presentation state only. It does not create/apply a decision, change a volume formula, or infer recovery from blocked/disrupted/insufficient evidence. Rotation, volume, and general legacy strategic copy remain deferred.

Historical warning is explicitly supporting-only. It maps to `watch` and never to `recovery_recommended` or `recovery_active`. Dashboard integration is blocked until shared action/verdict helpers stop reading `strategic.recommendation`.
