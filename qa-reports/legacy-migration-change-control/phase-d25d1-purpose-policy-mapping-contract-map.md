# D2.5D1 purpose-policy mapping contract map

| Contract field | Authority | Required | Validation / mapping influence | Output / consumer | Test |
| --- | --- | --- | --- | --- | --- |
| mapping schema + registry version | D2.5D1 registry | Yes | Exact known values only | Unsupported schema/registry result; D2.5D2/D3 gate | unknown version |
| goal | current setup goal contract | Yes | Must be `build_muscle` for this registry family | Programme-family classification | wrong goal |
| experience, days, split, equipment | setup/frequency/split/equipment contracts | Yes | Must exactly describe the declared family | `unsupported_programme_family` when valid but uncertified | beginner, two-day, restricted equipment |
| programme family + template family | D2.5C3 certification | Yes | Exact stable identities; never inferred from slots or order | Candidate policy projection | family mismatch |
| exact `MesocycleId` | mesocycle catalogue | Yes | Exact catalogue member and hypertrophy engine | Explicit matrix row only | unknown/generic/prefix purpose |
| policy/certification reference | D2.5C3 identity | Candidate only | Identity projection, not slot resolution | D2.5D2 equivalence input | base candidate |
| status/reason/capabilities | D2.5D1 support matrix | Yes | Candidate/dedicated/unsupported always non-executable | D2/D3 guard and advisory compatibility projection | all false capability checks |

The module is deliberately isolated from slot policy resolution, D2 construction, active-plan persistence, workouts, exact targets, legacy blocks and successor selection. It classifies one exact purpose/family only.
