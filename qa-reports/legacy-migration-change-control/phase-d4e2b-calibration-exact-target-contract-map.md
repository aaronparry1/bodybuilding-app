# D4E2B calibration exact-target contract map

| Contract | Approved owner | Output influence | Validation | Compatibility | Rollback |
|---|---|---|---|---|---|
| policy identity/scope | calibration policy registry | supported family only | exact IDs and versions | metadata-only | remove module |
| rep strategy | calibration rep policy | internal domain and exact target rule | class/lane coverage | future core comparison | remove contract |
| lane | slot purpose + exercise class | sub-policy composition | three explicit lanes | replaces block labels | remove resolver |
| set construction | D4B guidance + calibration policy | envelope and initial count | min ≤ max, no overflow | current semantic authority | remove policy |
| starting load | exercise history/loading capability | future load method | hierarchy and increment support | policy metadata only | remove policy |
| drop-off/shutdown | approved calibration safety policy | future stop metadata | threshold, reference, observation count | existing 15% rule documented | remove policy |
| effort/suitability | calibration execution policy | failure and admissibility metadata | no AMRAP/failure/RIR/RPE; explicit outcomes | no block suitability | remove policy |

The resolver has no wildcard/default row and resolves every supported lane/class combination only after exact purpose, session and guidance validation.
