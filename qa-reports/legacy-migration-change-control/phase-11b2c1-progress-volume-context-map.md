# Stage 2C1 Progress and volume context map

The current context resolver consumes only current plan identity, C1B current snapshots, and current decisions. `ready`, `in_progress`, insufficient, blocked, disrupted, review-required, no-current, compatibility, and invalid states remain explicit.

Current records take precedence over conflicting legacy active-block or block-decision data. Compatibility is read-only and cannot fabricate fatigue, exposure, objective success, successors, or decisions. Historical stored exact-target summaries remain outside this resolver and retain their Phase 4C authority.

Deferred: C2 Progress-dashboard adapter migration and C3 volume-formula adapter migration. This seam contains no dashboard calculation, formula implementation, writer, evaluator, application service, or UI.
